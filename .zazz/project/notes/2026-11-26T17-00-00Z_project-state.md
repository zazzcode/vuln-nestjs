# Project state

Date-time: 2026-11-26T17-00-00Z (12:00:00, UTC-5).

A deliberately vulnerable NestJS lab that measures the Zazzles SAST, SCA and DAST tools. The [README](../../../README.md) is the overview for readers, [AGENTS.md](../../../AGENTS.md) is the working guidance for agents, and [`docs/`](../../../docs/README.md) is the documentation for readers of the lab. The [implementation plan](../implementation-plan.md) is the build order. This note adds what they do not say. It supersedes the [project state](2026-11-26T15-38-03Z_project-state.md) of 15:38 UTC.

## What is built

Nothing runnable. The repository holds design and documentation:

- A [specification for each service](../services/README.md), with its API, its designed weaknesses and their protected counterparts. 74 scenarios on 62 vulnerable operations, and 118 safe operations.
- The [scenario catalogue](../scenario-catalog.md), the [build order](../implementation-plan.md), ten decision records, and the architecture revised for a star: services never call each other.
- The `spec-builder` and `handoff` skills, vendored in `.agents/skills/`.
- No application code, no `package.json`, no lockfile.

## What Step 1 must prove first

In this order, because each one can change the plan:

1. The code-first schema generator works with TypeScript 6, or the project falls back to TypeScript 5.9.3.
2. `pnpm install` succeeds with `allowBuilds` set for the two protobuf packages.
3. The gateway on Fastify composes three subgraphs written code first, over HTTP/2 to two of them.
4. TypeORM 1.1.3 reads and writes one entity through its MongoDB repository.
5. `mysql-memory-server` starts within a test timeout.
6. The lab stops cleanly: no engine process and no temporary directory left.

The [design revision](2026-11-26T17-00-00Z_design-revision.md) records what a spike on 2026-11-26 already verified, and the facts it taught about pnpm 12 and the Apollo gateway.
